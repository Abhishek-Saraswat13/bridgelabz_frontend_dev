## 🌐 About CSS

**CSS (Cascading Style Sheets)** is the language used to style and visually enhance web pages written in HTML.  
It controls **colors, fonts, spacing, layout, and responsiveness**, turning plain HTML into visually appealing and interactive designs.

CSS enables developers and designers to:
- 🎨 Create aesthetic user interfaces  
- 📱 Design responsive layouts for all screen sizes  
- ⚙️ Separate design from structure (HTML)  
- 🚀 Improve accessibility and user experience
