# 🌐 HTML — HyperText Markup Language

**HTML (HyperText Markup Language)** is the **foundation of the web**.  
It is the standard language used to **create and structure web pages** and web applications.  

Every website you visit — from simple text pages to complex apps — starts with HTML.

---

## 📖 Overview

HTML defines the **structure** of a webpage using a system of **elements** (also known as tags).  
These elements tell the browser **what to display** — such as text, images, links, tables, or forms — and **how to organize it**.

In simple terms:
> HTML = the *skeleton* of a website  
> CSS = the *style/clothing*  
> JavaScript = the *brains/interactivity*

---

## 🧠 What Does “HyperText Markup Language” Mean?

- **HyperText** → Refers to **links (hyperlinks)** that connect web pages together.  
- **Markup Language** → A language that uses **tags** to *mark up* (define) content structure.

---

## 🧩 Basic Structure of an HTML Document

Here’s the simplest valid HTML document:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First HTML Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is my first webpage using HTML.</p>
</body>
</html>
